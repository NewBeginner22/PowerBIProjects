HR Analytics Dashboard | Power BI
 Project Overview

This project focuses on cleaning, transforming, and analyzing a messy HR dataset to build an interactive HR analytics dashboard using Power BI.
The dashboard helps understand workforce distribution, attrition, salary trends, and key HR metrics.

 Dataset

File: messy_hr_dataset.csv

Key Columns:

Employee ID

Employee Name

Department

Designation

Gender

Employment Type

Join Date

Salary

Performance Rating

Attrition

Data Cleaning & Preparation

Data was cleaned using Power Query:

Standardized Gender, Department, Attrition values

Converted Salary and Ratings to numeric types

Fixed inconsistent date formats

Handled missing and null values

Created calculated columns and measures
